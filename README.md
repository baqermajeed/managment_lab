# مختبر دقة البوصلة — نظام إدارة حالات الأسنان

تطبيق ويب لإدارة حالات مختبر الأسنان: إدخال الحالات، الجدول اليومي/الشهري، وتقارير المصممين و Build Up.

## التشغيل

```bash
npm install
npm run dev
```

افتح الرابط الذي يظهر في الطرفية (عادة `http://localhost:5173`).

## الصفحات

1. **إدخال الحالات** — نموذج لإضافة حالة جديدة (طبيب، مريض، نوع العمل، وحدات، مصمم، Build Up).
2. **الجدول اليومي** — عرض الحالات مع فلترة يومية / شهرية / فترة محددة + إحصائيات عدد الحالات والوحدات.
3. **المصممين و Build Up** — جدول حالات كل شخص مع نفس خيارات الفلترة والإحصائيات.

## قاعدة البيانات (MongoDB)

هذه النسخة تستخدم **MongoDB** عبر Backend API.

### تشغيل MongoDB (Docker)

```bash
docker compose up -d
```

### تشغيل السيرفر

1) انسخ ملف البيئة:

```bash
copy server\\.env.example server\\.env
```

2) شغل السيرفر:

```bash
cd server
npm run dev
```

السيرفر يعمل على `http://localhost:4000` والواجهة الأمامية تستخدم `/api` تلقائياً عبر Proxy.
